# GRS Equipments — STETON HDD Website

India authorized dealer site for **GRS Equipments and Services LLP** (STETON 思特通 HDD / trenchless machines).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger (bore-path / reveal animations)
- React Router (multi-page)
- React Hook Form + Zod (contact form)

## Run

```bash
npm install
npm run dev
```
